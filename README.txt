ZOTAANG WEBSITE CLEANUP — LOCAL TEST PACKAGE

WHAT IS INCLUDED
- index.html: current homepage retained as the design reference.
- pages/: revised inner pages (phone, laptop, pricing, refurbished, about, contact).
- css/: separated shared inner-page, forms, and page-specific CSS.

IMPORTANT
1. Back up your existing website folder before copying anything.
2. This package intentionally does NOT include base.css, components.css, home.css, main.js, quote.js, or image assets. Keep your existing copies unchanged.
3. Keep your existing css/pages.css as a backup. The revised inner pages no longer load pages.css; they load base.css + components.css + inner-common.css + forms.css (where relevant) + their own page CSS.
4. The new pages are for LOCAL TESTING ONLY. Do not upload to GitHub until all pages and forms are checked.
5. Check the quote and refurbished forms, menu toggle, phone/WhatsApp links, map links, logo, and all navigation links.
6. The contact form action remains the existing Formspree endpoint. Do not change it unless you intend to change form handling.
7. Existing prices are preserved as shown in your supplied files.

COPYING
Copy the included pages/*.html into your existing pages/ folder, and the included css/*.css into your existing css/ folder. Replace index.html only if you want the included unchanged homepage copy.
Do not delete pages.css until every page has been tested and you are satisfied.

DESIGN
The page styling uses the existing blue/red/white variables and shared homepage shell. Inner pages use tighter hero spacing, more compact cards, and responsive grids.
